# Информационная система «Автошкола»

Учебная практика, РТУ МИРЭА, кафедра ИиППО, 5 семестр (осень 2026).
Студент: Скуратовский Г.Ю., группа ИКБО-15-24.
Тема: «Работа автошколы».

## Цель проекта

Автоматизация основного бизнес-процесса автошколы: от приёма заявки курсанта
и заключения договора до выпуска после внутреннего экзамена и передачи
документов для сдачи экзаменов в Госавтоинспекции.

## Среда разработки

Работа ведётся в Visual Studio Code с расширениями Python и Extension Pack for Java.
Используются Python 3.12, Java 21 (LTS), Apache Maven и система контроля версий Git.

## Структура репозитория

| Каталог   | Назначение                                                       |
|-----------|------------------------------------------------------------------|
| `docs/`   | Материалы отчёта: описание предметной области, глоссарий          |
| `python/` | Процедурная реализация алгоритмов (аналитический этап)            |
| `java/`   | Объектно-ориентированная реализация (организационный этап)        |
| `db/`     | Физическая модель данных: скрипты СУБД (проектный этап)           |

## План работ

- [x] Этап 1. Исследовательский (недели 1–4): анализ предметной области, настройка окружения
- [ ] Этап 2. Аналитический (недели 5–9): модель процесса, логическая модель данных, алгоритмы на Python
- [ ] Этап 3. Организационный и ООП (недели 10–12): реализация на Java, состав команды
- [ ] Этап 4. Проектный и тестирование (недели 13–15): база данных, тесты, качество кода
- [ ] Этап 5. Оформление отчёта (неделя 16)

## Соглашения

- Ветка `main` — стабильная версия; задачи выполняются в ветках `feature/<задача>`.
- Сообщения коммитов на русском языке, в повелительном наклонении.
- Стиль кода: PEP 8 для Python, Google Java Style для Java.
